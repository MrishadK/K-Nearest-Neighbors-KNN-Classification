## Overview
This project implements the K-Nearest Neighbors (KNN) algorithm for classification using the Iris dataset as an example. The implementation includes:

- Data preprocessing and normalization
- Model training with various K values
- Performance evaluation metrics
- Decision boundary visualization
- Accuracy analysis

## Features
✨ **Comprehensive Implementation**  
✅ Data normalization using StandardScaler  
✅ K-value optimization  
✅ Multiple evaluation metrics (accuracy, confusion matrix)  
📊 Beautiful visualizations  
🔍 Decision boundary analysis
